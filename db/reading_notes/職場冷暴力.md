
問題：如何避免? 如何應對?

人格缺陷
惡性：反社會、自戀、戲劇
良性：強迫、依賴、畏避
p26

反社會 -> 以自我為中心
自戀 -> 玻璃心
戲劇 -> 收割達人、八卦

強迫 -> 害怕失去控制
依賴 -> 跟風安全
畏避 -> 怕事而拖延
p77

冷暴力 3 種
1.直接 -> 濫權
2.間接 -> 玩弄體制
3.無形 -> 從文化上
p124

應對方式
1.找幫手
2.正面衝突
3.逆來順受

如何離職?
1.寄「討論生涯規劃」信給主管
2.面談講好「離職日」「工作交接」
3.別用離職求改變
4.一定要跟主管談完，再和同事講


覺察點：
1.以人格缺陷得六性格
2.認識其行為模式、生理反應，得幸運參數
3.情緒談吐中庸即可
4.離職注意事項

總結：
嚴己寬待人
把握幸運參數
環境惡劣則安全下庄 (離職)
