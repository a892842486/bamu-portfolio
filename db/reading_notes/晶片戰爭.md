光罩是一塊外面覆著一層 鉻 的玻璃板，完美複製紅色薄膜的圖案，最後再讓光罩曝光

創新者的兩難 (x86架構 vs ARM 架構)
Intel 守舊，錯失手機市場
葛洛夫 1987~1998 擔任 Intel 執行長
歐德寧 2005~2013 擔任 Intel 執行長
CPU (電腦中央處理器)，他的設計理念有兩個 複雜指令集電腦(CISC) / 精簡指令集電腦(RISC)
CISC (Complex Instruction Set Computer)
RISC (Reduced Instruction Set Computer)
x86 架構是基於 CISC 設計的，較複雜，不省電，但出現的年代早，所以廣為使用，至今 Intel / AMD 的 CPU 仍是此架構
ARM 架構是基於 RISC 設計的，較簡單，省電，但較晚出現，至今 手機 / iphone / imac 的 CPU 都是此架構

Intel 採用 x86 指令集架構持續幾年，柏克萊的電腦科學家設計一個更新、更簡單的晶片架構，稱為 RISC
(1975開始，1980完成 IBM 801 計畫，這可能是第一個使用 RISC 理念來設計的系統)
相較之下 x86 既複雜又笨重
葛洛夫曾認真考慮把 Intel 主要晶片轉成 RISC 架構，但改變的成本很高 (1980末 此時營收已突破2500億美元)，對 Intel 壟斷的地位威脅太大，所以放棄，因此，x86 是目前為止多數個人電腦的架構

同時 Intel 的 x86 也主宰伺服器事業，隨著企業在 2000 年代建造越來越大的資料中心，如.亞馬遜網路服務(AWS)、微軟 Azure、Google 雲端 (Google Cloud)
於 2000 年代中期，資料中心的晶片由 Intel 和 AMD 的 x86 晶片壟斷，沒有他們的處理器，雲端就無法運作

蘋果和兩個合作夥伴成立了 ARM 公司，目的是以 RISC 原則為基礎，設計新的處理器晶片
雖然在 2000 年代末期 ARM 未能獲得 個人電腦 的市占率，但 ARM 的簡化、節能架構，在必須節能省電的小型隨身裝置流行了起來，如.任天堂的掌上遊戲機、Ipod、還有之後的 Iphone
當賈伯斯 找 Intel 執行長歐德寧 要他們為蘋果生產 Iphone 手機晶片時，歐覺得 Iphone 只是小眾市場，而拒絕了，事後證明那是大錯特錯的預測
Iphone 趁勢而起，搶佔手機市場，Intel 直到很晚才投入手機市場，但為時已晚

Nvidia 不是唯一為專用邏輯晶片開創新用途的無晶圓廠公司
當時行動電話即將邁入 2G 技術，電話公司正在協議一種技術標準，讓他們的電話能互通，多數公司想用「分時多工」(time-division multiple access) 系統
在這個系統中，來自多個電話的資料是在相同的無線電波頻率上傳輸
當別的電話有片刻沉默時，某個電話的資料就會插入無線電波頻譜中

但很相信摩爾定律的 通訊理論教授 雅各布 認為另一種比較複雜的跳頻系統會更好，他建議在不同頻率之間移動通話資料，而不是把某通話固定在特定頻率上，就可以把更多的通話塞入可用的頻譜空間中

高通為 2G 以後的每一代手機技術，貢獻了如何透過無線頻譜傳輸更多資料的關鍵概念，並出售解讀這種雜訊的專用晶片

長年來，每一代的製造技術都是以 電晶體的 閘極長度 來命名的 (台積7奈米 5奈米)
閘極是矽晶片的一部份，其導電性會開啟與關閉 (連結與切斷電路)
180奈米製程是1999首次出現，隨後130nm, 90nm, 65nm, 45nm，每一代電晶體的體積都縮小 足以在同一區域容納兩倍的電晶體，這降低了每個電晶體的功耗，因為更小的電晶體需要更少的電子流過它們

為了更好地控制電子的流動，需要新的材料和電晶體的設計，22nm的節點和1960年代以來使用的 2D 設計不同，它導入一種新的 3D 電晶體，稱為鰭式場效電晶體 (FinFET)
它把 電路的兩端 和 連接它們的半導體材料通道放在矽片上方，看起來像鯨魚的背鰭
因此，連接電路兩端的通道不僅可以從頂部施加電場，也可以從鰭片側面施加電場，從而增強對電子的控制。並克服威脅新一代電晶體的漏電問題 (克服 量子穿隧效應 Quantum tunneling effect)

但這些奈米級的 3D 結構 製造難度極高，在沉積、蝕刻、微影成像都需要更精密，也增加了不確定性，晶片製造商都能完美的切換成 FinFET 架構嗎?

此時剛好遇到2008~2009美國次級房貸危機 (金融海嘯)，但台積電2009~2010依然每年增加十億美元的資本支出， 他說「產能太多比產能不足」更好

這是一個由數十家公司組成的合作關係，分別設計晶片、銷售智慧財產權、生產材料、製作機台
